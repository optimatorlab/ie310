# Dummy Orbit 🪐

Welcome to **Dummy Orbit**, the world’s least necessary satellite program.

This folder contains absolutely no flight software, telemetry, or mission-critical
anything. Its only job is to gently circle an imaginary planet while collecting
ideas that were too strange for a normal to-do list.

## Mission objectives

- Launch one harmless thought into low imagination orbit.
- Give every unfinished idea a tiny astronaut helmet.
- Return useful nonsense to Earth before lunch.

# Moonlit Workbench

Welcome to the **Moonlit Workbench** — a quiet corner for experiments that are not ready to become important yet.

## What belongs here?

- Half-formed ideas
- Tiny prototypes
- Curious notes
- Anything that benefits from a little imaginary moonlight

## Operating principle

> Make it interesting first. Make it useful second.

This folder is intentionally harmless, temporary, and delightfully overqualified for storing absolutely nothing important.

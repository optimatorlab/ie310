---
name: grillme
description: Interviews the user relentlessly about a coding plan before implementation. Use when the user asks to plan a coding project, feature, refactor, architecture change, or implementation approach and wants rigorous questioning, design-tree exploration, codebase-informed answers, and a final Markdown plan instead of code edits.
---

Interview me relentlessly about every aspect of this plan until we reach a shared understanding. Walk down each branch of the design tree, resolving dependencies between decisions one by one. And finally, if a question can be answered by exploring the code base, explore the code base instead.

Do not edit any code. Instead, after we converge to a plan, write a .md file clearly describing the plan.
